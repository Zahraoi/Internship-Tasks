1. Assigned Tasks
This week, I was assigned to build a complete full-stack Personal Finance Dashboard using modern web technologies. The tasks included:
1. Personal Finance Dashboard - Full Stack Development
• Built a complete Personal Finance Dashboard with React frontend and Node.js/Express backend.
• Implemented MongoDB Atlas database for data storage.
• Created a responsive user interface using Tailwind CSS.
2. Authentication System
• Developed user registration and login functionality.
• Implemented JWT-based authentication with protected routes.
• Added logout functionality.
3. Dashboard Module
• Created a dashboard displaying summary cards: Income, Expense, Balance.
• Added month filtering selector for viewing specific month's data.
• Included undo/redo buttons for transaction actions.
• Added CSV export functionality for transactions.
4. Transaction Management Module
• Implemented Add, View, Edit, and Delete functionality for transactions.
• Added categories: food, transport, entertainment, shopping, bills, health, income, other.
• Included debounced search and category filtering.
• Displayed transactions grouped by month.
5. Budget Management Module
• Created functionality to set monthly budgets by category.
• Added visual progress bars showing budget utilization.
• Implemented budget alerts (approaching limit and exceeded).
6. Reports Module
• Built monthly spending bar chart using Recharts.
• Created category breakdown pie chart.
• Added clickable charts for detailed view.
7. Sidebar Navigation
• Created sidebar with Dashboard, Transactions, Budget, Reports, Settings tabs.
• Implemented smooth scroll to sections when clicking sidebar items.
• Added highlight animation on sidebar navigation.
8. Dark/Light Mode
• Implemented full dark mode support throughout the application.
• Added toggle button in the sidebar for theme switching.
9. Currency Configuration
• Configured all amounts to display in Pakistani Rupees (Rs.).
