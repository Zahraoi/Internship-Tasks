

#  Tailwind CSS Portfolio Website

## Project Overview

This project is a **responsive personal portfolio website** built using **HTML5, Tailwind CSS, and JavaScript**.

The purpose of this project was to design and develop a modern, clean, and fully responsive developer portfolio showcasing personal information, skills, experience, projects, testimonials, and contact details.

The website includes a fully responsive navigation bar, dark mode toggle functionality, multiple structured sections, and a clean UI built entirely using Tailwind utility classes.

---

##  Technologies Used

* **HTML5**
* **Tailwind CSS (CDN version)**
* **JavaScript (for dark mode toggle & mobile menu)**

No custom CSS file was used — all styling is handled using Tailwind utility classes.

---

##  Features

*  Fully responsive layout (mobile, tablet, desktop)
*  Dark mode toggle functionality
*  Mobile hamburger menu

## ▶ How to Run the Project

1. Download or clone the repository
2. Open `index.html` in any modern web browser
3. Make sure the `images` folder is in the correct path

No installations or build tools are required.

---

##  Responsiveness

The layout is built using Tailwind’s responsive breakpoints:

* `sm`
* `md`
* `lg`
* `xl`

The website adapts smoothly across different screen sizes.

---

##  Dark Mode

Dark mode is implemented using:

* Tailwind’s `dark` class
* JavaScript toggle functionality
* Dynamic class switching on the `<html>` element
